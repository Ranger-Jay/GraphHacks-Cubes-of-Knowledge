# Cinematic presentation and camera controls

The visual reference is `cubes_of_knowledge_3d.html`. Production retains its API,
authorization, snapshot generation, evidence paths, Explain validation and approved
recorded voices. No reference-page simulated queries, imports, outages, hashes,
invented counts, or success indicators are used.

## Camera

- The red comparison cube sits four main-cube widths from the main cube's center.
  Their rotating bodies retain at least two main-cube widths of clear space.
- Initial view and **Show both cubes** frame both bodies, including portrait screens.
- Wheel up / pinch apart / **+** zoom in. Wheel down / pinch together / **−** zoom out.
- **Main cube** restores its close-up. **Focus disconnected cube** inspects the red
  comparison. It has no database and does not acquire production graph authority.
- Drag turns the cube or camera. Right-drag / Shift-drag orbits the camera.
- Explicit zoom works with reduced motion; automatic ornament animation does not.

## Appearance

Dark cosmic palette, glass HUD and evidence panels, cyan/purple highlights,
an aperture-style agent opening, the existing stylized SVG portraits, procedural
pyramid circuitry/name badges/apex gems, a solar gyroscopic dial and paired frame
lights extend the existing stars, liquid starlight and solar corona.

Ornaments are decorative. They create no graph records or evidence edges. Ready-only
solar/frame highlights disappear when the current runtime leaves READY. Browser
fonts and procedural textures require no external asset service. Missing external
portrait PNGs referenced by the prototype are not fabricated; the accepted SVGs
remain in use. Portraits have idle breathing/blinking and a smile, not invented
lip sync for arbitrary model replies.

## Sound

Audio remains muted on entry. After explicit unmute, a READY-state gesture can play
a short local aperture sweep or pentatonic camera chime. No ambient autoplay,
network synthesis, extra recordings or provider calls are introduced. Both recorded
speech and local read-aloud take priority; effects stop on mute, non-READY phase,
hidden page and unmount. Effects never announce approval, import or task success.

## Verification limits

Camera bounds/picking, bounded ornament geometry, texture disposal and audio lifecycle
have automated tests. The full existing offline verification remains required.
GPU appearance and audible quality still require a browser/device with WebGL/audio;
a headless fallback does not establish those results. Model inference is separate
from this presentation change. The latest README is preserved byte-for-byte.
